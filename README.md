# MultyAudioOutput

Маленький застосунок у треї Windows 10/11 для вибору **пристрою виводу звуку для кожної програми окремо**.
Наприклад: гра → провідні навушники, браузер/відеоплеєр з фільмом → Bluetooth-навушники.

## Можливості
- Панель у треї (ЛКМ по іконці навушників): список програм зі звуком, для кожної — вибір пристрою, гучність, mute.
- Запам'ятовує вибір (`програма → пристрій`) і автоматично застосовує його після перезапуску програми
  та після перепідключення Bluetooth-навушників.
- Гарячі клавіші (змінюються в налаштуваннях):
  - `Ctrl+Alt+F10` — перемкнути програму в активному вікні на наступний пристрій;
  - `Ctrl+Alt+F11` — показати/сховати панель.
- Автозапуск разом з Windows (меню трею або налаштування).
- Світла/темна тема за системною.

## Збірка та запуск
Потрібен .NET 8 SDK.

```bash
dotnet run --project src/MultyAudioOutput
```

Один самодостатній `.exe` (не потребує встановленого .NET):

```bash
dotnet publish src/MultyAudioOutput -c Release -o publish
```

Результат — один файл `publish\MultyAudioOutput.exe` (~70 МБ, .NET і всі DLL всередині).

## Оновлення
Застосунок сам перевіряє GitHub Releases репозиторію `MykhailoKhmaruk/MultyOutputAudioManager`
(через 15 с після запуску й далі кожні 6 год; вимикається в налаштуваннях). Якщо є новіша версія —
сповіщення в треї та кнопка «Оновити» в панелі: exe завантажується, замінює себе і перезапускається.

Як випустити нову версію:
1. Підніміть `<Version>` у `src/MultyAudioOutput/MultyAudioOutput.csproj` (наприклад `0.3.0`).
2. Зберіть: `dotnet publish src/MultyAudioOutput -c Release -o publish`.
3. На GitHub → Releases → *Draft a new release*: тег `v0.3.0`, прикріпіть файл `publish\MultyAudioOutput.exe`
   (назва файлу саме така), опублікуйте.

Репозиторій має бути публічним — інакше програма не побачить релізів.

## Як це працює
Використовується той самий механізм Windows, що й у «Параметри → Звук → Гучність програм»
(недокументований `IAudioPolicyConfigFactory`, як в EarTrumpet / SoundSwitch). Гучність і сесії — через NAudio (Core Audio).

Обмеження:
- Браузер перемикається повністю, не окремі вкладки.
- Деякі програми/ігри підхоплюють новий пристрій лише після паузи/перезапуску відтворення.

## Дані
`%AppData%\MultyAudioOutput\settings.json` — правила й налаштування, `log.txt` — помилки.
`MultyAudioOutput.exe --diag` записує `diag.txt` з переліком пристроїв і програм.
